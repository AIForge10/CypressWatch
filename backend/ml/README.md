# Hazard-index model

- `data/raw/`: downloads (NOAA Storm Events, OSHA, Open-Meteo archive). Git-ignored.
- `data/processed/`: training tables. Git-ignored.
- `notebooks/`: exploration. Name notebooks `NN-topic.ipynb`.
